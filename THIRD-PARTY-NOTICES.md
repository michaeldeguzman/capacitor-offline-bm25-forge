# Third-party notices

## Porter stemming algorithm

The stemmer in `ios/Plugin/PorterStemmer.swift` and `android/src/main/kotlin/com/michaeldeguzman/plugins/offlinebm25/PorterStemmer.kt` implements the algorithm in M. F. Porter, "An algorithm for suffix stripping", *Program* 14(3), 1980, pages 130 to 137. The ports follow the structure of Porter's own reference implementation, through the C# port in BM25Engine (see below).

`tests/fixtures/stemmer.json` includes 87 word and stem pairs sampled from Porter's official test vocabulary, which is published at https://tartarus.org/martin/PorterStemmer/. They are there to test the ports and are not part of the shipped plugin code.

## BM25Engine

BM25Engine is a C# External Logic component for OutSystems Developer Cloud, written by the author of this plugin. It is the reference implementation for the tokenizer, the stop-word list, the Porter stemmer and the BM25 scorer. The Swift and Kotlin code here is a port of that code, and `tests/fixtures/` is generated by running it. See `tests/fixtures/README.md`.

## BM25

The scoring follows Okapi BM25 (Robertson, Walker and others, 1994) with the always-positive inverse document frequency used by Lucene and Elasticsearch, `ln((N - n + 0.5) / (n + 0.5) + 1)`.
